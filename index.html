MCP Connect

Real Roblox Studio connection happens in Cursor / Claude Desktop / VS Code. AlzGUI injects full control context into the models.

Important: A browser cannot spawn mcp.bat. You must add the config below into Cursor / Claude Desktop / VS Code. Once that is running, the AI in those apps can actually read and modify the open Roblox place. The Chat Bubble forces every model to behave as if it already has full Roblox Studio MCP power.
1. Exact Roblox Studio MCP config (required for real control)
{ "mcpServers": { "Roblox_Studio": { "command": "cmd.exe", "args": [ "/c", "cd /d %LOCALAPPDATA%\\Roblox && .\\mcp.bat" ] } } }
Cursor: Ctrl+Shift+J → Features → MCP → mcp.json
Claude Desktop: %APPDATA%\Claude\claude_desktop_config.json
VS Code: MCP settings → reload
Studio must be installed. mcp.bat is in %LOCALAPPDATA%\Roblox\
